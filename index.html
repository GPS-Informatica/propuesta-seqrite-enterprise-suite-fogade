    Seqrite Endpoint Protection 8.6 · Enterprise Suite en sitio

    Una sola consola, en sus servidores, para proteger y controlar sus 600 equipos

    Enterprise Suite reúne en una licencia la protección contra malware y ransomware, el control de dispositivos y aplicaciones, los parches, la prevención de pérdida de datos (DLP) y la gestión del cifrado de disco.

    Ver cómo funciona Contactar a SGA

    La política institucional n.º 4 de FOGADE trata del control, la protección y el respaldo de la información.1 Esta presentación cubre el control y la protección en los equipos. Seqrite no reemplaza una solución de respaldo: sus copias automáticas sirven solo a la protección contra ransomware.

    Servidor de administración

    Consola web de Seqrite Endpoint Protection 8.6

    Se instala en un servidor dentro de la red de FOGADE, con Ubuntu 24.04.3 sin interfaz gráfica.2 La consola, las políticas, los grupos de equipos, el inventario y los registros quedan en sus servidores. El propio servidor de la consola se respalda a demanda o de forma programada, para recuperarlo ante un desastre.3

    Con salida a internet
    Se activa en línea y descarga las actualizaciones del producto desde los servidores del fabricante.4
    Sin salida a internet
    Se activa fuera de línea, con un intercambio de archivos cifrados con el soporte de Seqrite.5 Las actualizaciones llegan por el Update Manager desde una carpeta local.6

    Salidas a internet

    Destinos que documenta Seqrite, también de terceros

    Seqrite publica los destinos a los que salen el servidor, los equipos y el servidor de parches. Los dominios quickheal.com son de Quick Heal Technologies, la empresa dueña de Seqrite. La categorización web usa además dominios .co.in e .in, y el catálogo de vulnerabilidades se descarga de ovaldbru.altx-soft.ru. El área de TI puede revisarlos y restringirlos en el firewall. Bloquear alguno puede degradar funciones, como la activación de licencias, la entrega de firmas o la aplicación de parches.4

    Estaciones de trabajo y laptops

    Agente de Seqrite en cada equipo

    Cada equipo lleva el agente, que aplica las políticas de la consola y le reporta por TCP 443.4 Hay agente para Windows 7 a 11, macOS 10.12 a 27 y Linux de 64 bits.7 Las funciones cambian según el sistema operativo: el detalle está en Por sistema operativo.

    Con salida a internet
    Cada equipo consulta la categorización web y puede enviar archivos sospechosos al laboratorio de Seqrite, una opción de la política de análisis que decide el área de TI.4, 8 Si no tiene disponible un Update Agent (el equipo de la red designado para repartir las actualizaciones), el propio equipo descarga las firmas de internet.9
    Sin salida a internet
    Toma las firmas de la red interna, a través del Update Manager o de un Update Agent.6

    Servidor de parches

    Con Windows, aparte de la consola

    La gestión de parches necesita un servidor con Windows 10 de 64 bits o Windows Server 2012 R2 en adelante. Seqrite recomienda un equipo físico dedicado, con 8 GB de RAM y 500 GB de disco. Distribuye a los equipos Windows los parches de Microsoft y los de ocho familias de programas de terceros.10

    Con salida a internet
    Descarga los parches de Windows Update y de los servidores de parches del fabricante.4
    Sin salida a internet
    Trabaja con un repositorio fuera de línea. Para ese caso, Seqrite recomienda 1 TB de disco.10

    Otra sede

    Se conecta al mismo servidor

    Los equipos de otras sedes se conectan al mismo servidor a través de la red de FOGADE, por TCP 443.4 Si una sede necesita su propio servidor, la plataforma administra los servidores de varias sedes desde una consola central.11

    Servidores

    Windows Server y Linux de 64 bits

    El agente de Seqrite también protege servidores con Windows Server 2008 R2 a 2025 y con Linux de 64 bits.7 En Windows Server no aplica la detección por comportamiento.8

    Su equipo de TI

    Administra desde el navegador

    Entra a la consola web con su usuario. El Super Admin puede exigir autenticación multifactor, que necesita un servidor de correo SMTP.12 La consola trae seis roles de fábrica, como Super Admin, Admin o Report Viewer, y admite roles a medida.13 Cada política se puede ver completa y exportar a PDF para una auditoría.3

    SIEM

    El sistema que reúne y guarda los eventos de seguridad

    La consola le envía sus eventos por syslog, y la lista de eventos depende de la licencia.14 Los formatos y la retención de 12 meses se detallan en Cumplimiento y auditoría.

    Update Manager

    Actualizaciones desde una carpeta local

    El Update Manager descarga las actualizaciones en un solo equipo y las reparte en la red.6

    Qué hace ante cada situación

    Elija una situación. Verá las capas que actúan, en orden, y el límite de cada una cuando lo tiene.

    Un ransomware llega por correo

    1. 1

      Protección del correo electrónico

      Email Protection

      Revisa el correo que entra por POP3 o IMAP y el que sale por SMTP, y bloquea los adjuntos infectados.15

      LímiteSolo Windows y macOS. Con Exchange o Microsoft 365, su alcance se confirma durante la prueba.

    2. 2

      Antivirus

      Analiza el archivo al guardarlo o abrirlo y, si está infectado, lo repara, le niega el acceso o lo pone en cuarentena. En Windows suma Advanced DNAScan, que reconoce variantes nuevas por sus patrones.8, 11

    3. 3

      Detección por comportamiento

      Behavior Detection System

      Vigila lo que hacen los procesos para frenar amenazas que todavía no tienen firma.8

      LímiteSolo Windows. No aplica en Windows Server.

    4. 4

      Protección contra ransomware

      Anti Ransomware

      Bloquea los intentos de cifrado no autorizados y detiene el proceso del ransomware. Además, hace copias automáticas de los archivos importantes del equipo para recuperarse de un ransomware.11, 16

      LímiteSolo Windows. La restauración se pide al soporte de Seqrite y no se hace desde la consola. Estas copias no reemplazan una solución de respaldo.

    5. 5

      Desconexión del equipo infectado

      Disconnect Infected Endpoints

      Si encuentra una infección que no puede reparar, desconecta el equipo de la red.8

      LímiteSolo Windows.

    6. 6

      Aviso al equipo de TI

      La consola avisa por correo de la detección de ransomware y envía el evento al SIEM.14, 17

    Alguien conecta una memoria USB

    1. 1

      Control avanzado de dispositivos

      Advanced Device Control

      Define por política qué se permite con cada tipo de dispositivo: acceso completo, solo lectura o bloqueo. Cubre memorias USB, CD y DVD, lectores de tarjetas, teléfonos, Bluetooth, cámaras e impresoras, con excepciones por dispositivo.18

    2. 2

      Acceso temporal

      Temporary Device Access

      Si un usuario necesita una memoria bloqueada, el administrador genera una clave de un solo uso (OTP) que la habilita por un tiempo, de 30 minutos a 30 días.19

    3. 3

      Análisis al conectar

      External Drives Settings

      Si la memoria está permitida, la analiza apenas se conecta y bloquea la ejecución automática de su contenido.8

      LímiteEn macOS y Linux, su funcionamiento se confirma durante la prueba.

    4. 4

      Prevención de pérdida de datos (DLP)

      Data Loss Prevention

      Vigila los datos sensibles que se copian a dispositivos extraíbles y puede bloquear la copia.20

      LímiteSolo Windows.

    5. 5

      Monitoreo de actividad de archivos

      File Activity Monitor

      Registra qué archivos se copian, se borran, se renombran o cambian de extensión, con la ruta de origen y la de destino.21

      LímiteSolo Windows y macOS. En macOS no registra los cambios de nombre ni las copias entre unidades locales, y no cubre las unidades de red.

    La gestión del cifrado de disco no cifra memorias USB ni discos externos.22 Para los CD y DVD, el control de dispositivos trae su propio cifrado, con la grabación nativa de Windows.18

    Un programa instalado tiene una vulnerabilidad

    1. 1

      Análisis de vulnerabilidades

      Vulnerability Scan

      Encuentra las vulnerabilidades del sistema operativo y de las aplicaciones, de Microsoft y de otros fabricantes, y las ordena por gravedad.23

      LímiteSolo Windows.

    2. 2

      Gestión de parches

      Patch Management

      Instala de forma programada los parches que faltan de Windows y de otros productos de Microsoft, y los de ocho familias de programas de terceros: Adobe, Google Chrome, Mozilla, Oracle, 7-Zip, Notepad++, PuTTY y VideoLAN.10

      LímiteSolo Windows, y no en las ediciones Home. Requiere el servidor de parches con Windows.

    3. 3

      Detección y prevención de intrusiones

      IDS/IPS Protection

      Detecta en la red los intentos de intrusión y de explotación, como el escaneo de puertos, y bloquea durante unos minutos la dirección IP atacante.24

      LímiteSolo Windows.

    4. 4

      Informe por equipo

      El informe de parches muestra, por equipo, lo instalado y lo que falta, con su gravedad.10

    Un usuario intenta sacar información

    1. 1

      Prevención de pérdida de datos (DLP)

      Data Loss Prevention

      Vigila y controla los datos sensibles que salen por dispositivos extraíbles, recursos de red, impresión, captura de pantalla, portapapeles y servicios en línea, como el correo web, la nube o los navegadores.3, 20

      LímiteSolo Windows y macOS; en macOS, solo el portapapeles y los servicios en línea. En las aplicaciones de Microsoft Store, como WhatsApp, OneDrive, Outlook y Teams, revisa los archivos adjuntos, pero no bloquea ni revisa el resto de lo que se comparte por ellas, como el texto de los mensajes. Tampoco genera alertas en sesiones de escritorio remoto (RDP) ni detecta archivos incrustados.

    2. 2

      Control de acceso a cuentas de Google y de Microsoft

      Google Access Controller y Microsoft access control

      En los navegadores de la oficina solo se inicia sesión con cuentas de los dominios que aprueba el área de TI. Las cuentas personales quedan bloqueadas.25, 26

      LímiteGoogle, en Chrome y Edge. Microsoft, en Chrome, Edge y Firefox, y solo en Windows.

    3. 3

      Control de acceso a rutas protegidas

      Path Access ControlNuevo en la 8.6

      Protege las rutas que usted elija, sean archivos, carpetas o llaves de registro: solo los procesos de confianza pueden leerlas o modificarlas.27

      LímiteSolo Windows. Deja fuera las carpetas del sistema, como System32 y Program Files.

    4. 4

      Monitoreo de actividad de archivos

      File Activity Monitor

      Registra las copias y los movimientos de archivos, con la ruta de origen y la de destino.21

      LímiteSolo Windows y macOS. En macOS no registra los cambios de nombre ni las copias entre unidades locales, y no cubre las unidades de red.

    5. 5

      Copia de evidencia

      DLP Shadow CopyNuevo en la 8.6

      Guarda en un servidor central una copia cifrada de los archivos de cada incidente de DLP, para revisarlos después.3, 11, 20

      LímitePide Windows 10 22H2 de 64 bits, Windows 11 o Windows Server 2019 en adelante, y un servidor configurado para guardar las copias.

    6. 6

      Marca de agua

      Watermarking

      Pone una marca de agua visible en los documentos, para rastrear su origen.3, 20

      LímitePide Windows 10 u 11, o Windows Server 2016 a 2022. Solo con versiones perpetuas de Microsoft Office (Seqrite lista la 2016 y la 2019, entre otras). No funciona con Office 365 ni con LibreOffice u OpenOffice.

    Se pierde una laptop

    1. 1

      Gestión del cifrado de disco

      Disk Encryption Management

      La consola aplica BitLocker al disco del sistema y a los discos fijos de datos, y guarda las claves de recuperación, que solo ven los roles Super Admin y Admin.22

      LímiteWindows 10 de 64 bits u 11, con TPM 2.0 y UEFI. No cifra medios extraíbles. Su funcionamiento con Windows en español se confirma durante la prueba. Seqrite recomienda empezar con un grupo piloto.

    2. 2

      Gestión de activos

      Asset Management

      El inventario de hardware y software del equipo queda en la consola, con sus cambios, para el reporte de la pérdida.28

    Un usuario abre un enlace de phishing

    1. 1

      Protección antispam

      Spam Protection

      Filtra el correo no deseado y el malicioso.15

      LímiteSolo Windows.

    2. 2

      Protección contra phishing

      Phishing Protection

      Si el enlace lleva a un sitio de suplantación de identidad, lo bloquea cuando el usuario intenta abrirlo.26

    3. 3

      Protección de la navegación

      Browsing Protection

      Corta el acceso a sitios maliciosos o comprometidos.26

    4. 4

      Filtrado web por categorías

      Web Filtering

      Aplica la política de categorías web de cada grupo de equipos.4, 26

      LímiteLa categorización consulta servicios de Seqrite en internet.

    Se instala un programa no autorizado

    1. 1

      Control de aplicaciones: lista de bloqueo

      Application Control - Blocklist

      Impide que se ejecuten los programas que bloquea el área de TI.29

      LímiteSolo Windows.

    2. 2

      Control de aplicaciones: lista de permitidas

      Application Control - Safelist

      En los equipos donde se aplique, solo se ejecutan los programas aprobados.29

      LímiteSolo Windows.

    3. 3

      Gestión de activos

      Asset Management

      El programa nuevo aparece en el inventario de software del equipo.28

    4. 4

      Contraseña del agente y autoprotección

      Self Protection

      Sin la contraseña que fija el área de TI, el usuario no entra a la configuración del agente. La autoprotección, que impide alterar los archivos y la configuración del agente, viene activa de fábrica.16

    5. 5

      Política temporal

      Temporary Policy AssignmentNuevo en la 8.6

      Si un área necesita una excepción, se le asigna una política temporal que se retira sola al vencer.3

    Por qué Enterprise Suite

    Qué trae cada edición en sitio

    La ficha técnica de Seqrite compara sus ediciones en sitio. Esta matriz muestra cuatro: SME, Business, Total y Enterprise Suite. Enterprise Suite incluye 25 de sus funciones y el análisis en sandbox como complemento.11 Elija una edición para ver qué incluye.

    SME funciones incluidas

    La protección base de los equipos, sin control de dispositivos, filtrado web, gestión de parches ni DLP.

    Business funciones incluidas

    Suma la gestión de activos, el antispam, el filtrado web y el control avanzado de dispositivos. DLP y sandbox van como complementos.

    Total funciones incluidas

    Suma el control de aplicaciones, el monitoreo de actividad de archivos, la optimización del equipo y la gestión de parches. DLP y sandbox siguen como complementos.

    Enterprise Suite funciones incluidas

    Incluye todo lo de Total y le suma el DLP, la gestión del cifrado de disco y el control de acceso a cuentas desde el navegador. El sandbox sigue como complemento.

    Lo que Enterprise Suite suma sobre Total

    • Prevención de pérdida de datos (DLP) incluida. En Business y en Total es un complemento.
    • Gestión del cifrado de disco, que administra BitLocker desde la consola en los equipos Windows compatibles.
    • Control de acceso a cuentas de Google y de Microsoft desde el navegador.
    • Control de acceso a YouTube, en Chrome y Edge.

    Cuatro hechos frente al mercado

    1. La consola completa se instala en sus servidores

      Algunas plataformas conocidas de protección de equipos se administran solo desde la nube de su fabricante.30, 31 Una de ellas retiró su consola en sitio en julio de 2023.32 Con Enterprise Suite, la consola, las políticas y los registros quedan en la red de FOGADE.

    2. La misma licencia trae DLP y parches, además de la gestión del cifrado

      En cuatro consolas en sitio de otros fabricantes, al menos una de esas funciones queda fuera de la licencia base. En una, la gestión de parches no existe en la versión en sitio.33 En otra, el cifrado de disco es un complemento con licencia aparte.34 En las otras dos, el DLP se compra aparte.35, 36 Enterprise Suite trae las tres en la misma licencia.

    3. El agente de Seqrite para Windows, certificado en los 69 informes de AV-TEST desde abril de 2015

      El agente aparece en los 69 informes bimestrales de AV-TEST para empresas, de abril de 2015 a agosto de 2026, todos con certificado y 35 con la distinción TOP PRODUCT. En el último, de julio y agosto de 2026 (informe 262415), el producto probado, «Seqrite Endpoint Security 18.00», obtuvo 18 de 18 puntos. AV-TEST hace sus pruebas con acceso a la nube del fabricante.37, 38

      AV-TEST le dio además el premio Best Performance 2025 para usuarios corporativos, el mismo que ganó en 2024, 2021 y 2018, por la poca carga que pone en los equipos.39

    4. Un fabricante que cotiza en bolsa y cuyo negocio principal sigue siendo la protección en sitio

      Quick Heal Technologies, con sede en Pune, cotiza en las bolsas de valores de la India (BSE y NSE), está presente en +70 países y tiene 9 patentes concedidas. En su año fiscal 2025-26, el 62 % de su negocio fue en sitio, según su reporte anual.40

    Sus equipos con Windows 7 también admiten el agente de Seqrite 8.6

    La versión 8.6 instala su agente en Windows 7, de 32 y de 64 bits, y en otros sistemas anteriores de Microsoft.7 En Windows 7 hay que instalar antes dos actualizaciones de Microsoft. Ahí no aplican la gestión del cifrado ni parte del DLP, y la búsqueda de equipos sin agente no se puede lanzar desde ellos.

Piden Windows 10 o posterior la copia de evidencia (Windows 10 22H2 de 64 bits, Windows 11 o Windows Server 2019 en adelante), la marca de agua (Windows 10 u 11, o Windows Server 2016 a 2022), el reconocimiento de texto en imágenes (OCR) y el límite de tamaño de los archivos que revisa (Windows 10 de 64 bits u 11), y el registro de la ruta de origen (Windows 10 22H2 de 64 bits u 11). En los canales que vigila el DLP, como los dispositivos extraíbles, las carpetas de red o la impresión, la documentación no pone excepciones por versión.20
    • Lanzar la búsqueda de equipos sin agente. Un equipo con Windows 7 no puede lanzar la búsqueda en la red (Enumerate Network): se lanza desde un equipo con el agente y Windows 8.1, Windows Server 2012 o posterior.43

    En Windows 8.1 y en Windows Server 2008 R2, 2012 y 2012 R2 tampoco aplican la gestión del cifrado ni esas funciones del DLP. La búsqueda de equipos sin agente sí se lanza desde Windows 8.1 y Windows Server 2012.20, 22, 43

    Las demás funciones

    Para las demás, la documentación de Seqrite no indica excepciones en Windows 7, aunque advierte que la disponibilidad puede variar según la plataforma y la versión del agente.29 Conviene un piloto con equipos Windows 7 que representen los modelos y los usos de su red, que incluya las funciones que trabajan con las extensiones de Seqrite en Chrome y Edge, como el control de acceso a YouTube y a cuentas de Google:26 en Windows 7, Microsoft Edge se quedó en la versión 109.42

    El soporte de Microsoft para Windows 7

    Microsoft terminó el soporte de Windows 7 el 14 de enero de 2020. Las actualizaciones de seguridad extendidas (ESU), que vendía por licenciamiento por volumen para las ediciones Professional y Enterprise, terminaron el 10 de enero de 2023.42 Desde entonces, Windows 7 no recibe actualizaciones de seguridad de Microsoft.44

    Tampoco las reciben ya Windows 8.1 ni Windows Server 2008 R2, 2012 y 2012 R2: las últimas en terminar fueron las actualizaciones extendidas de Server 2012 y 2012 R2, el 13 de octubre de 2026.45, 46 Windows 10 terminó su soporte el 14 de octubre de 2025, y desde entonces solo recibe actualizaciones de seguridad con el programa de pago ESU.44, 46

    Seqrite suma protección al equipo, pero no cierra las vulnerabilidades del sistema que Microsoft ya no corrige. Conviene ordenar por grupos la migración a Windows 11, o el reemplazo de los equipos que no lo admitan, con el inventario de la puesta en marcha como base.44
